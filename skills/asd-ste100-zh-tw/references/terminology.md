# 術語與語意控制

本檔為繁體中文改編的補充指引，不是 ASD 核准詞典。依概念選詞；不對引文、介面名稱、程式碼或識別字做全域替換。

## 依領域辨識術語

依序參考當次任務指定且概念正確的名稱、專案既有定義與目標讀者所用的領域慣用譯名。名稱不一致或概念有歧義時，指出差異；不要自行合併。沒有穩定譯名才保留英文，必要時簡釋。

| 詞組 | 需要保留的區別 |
| --- | --- |
| accuracy/precision | 分類指標與量測品質的用法不同；先辨識領域，不將所有 precision 都改成精確率。 |
| validation/verification/test | 區分資料切分、規格查驗及實際測試；有混淆時保留英文以對照定義。 |
| calibration | 先確認是相機幾何、量測儀器或預測機率的處理，再沿用該領域術語。 |
| detection/identification/tracking | 發現對象、確認身分與維持時間對應是不同工作。 |
| latency/throughput | 延遲與吞吐量分別陳述，不能只用「速度」代替兩者。 |
| memory/storage/VRAM | 記憶體、儲存空間與 GPU 記憶體分開，不互換容量。 |

不預設任何人的固定用字，亦不為上述詞組建立跨領域的一對一譯名。

## 情態與量詞

| 表達 | 應保留的意思 |
| --- | --- |
| 必須/建議 | 要求與建議不同；不將建議提升為義務。 |
| 允許/能夠/可能 | 許可、能力與不確定性不同。「可」不足以判定時，保留原字或釐清。 |
| 不得/不建議/不需要 | 禁止、負面建議與非必要不同。 |
| 尚未觀察到/未檢出 | 僅表示原文所述觀察或檢出範圍內沒有相關結果，不代表事物不存在；保留原文的時間與樣本範圍。 |
| 只有 A 才 B/只要 A 就 B | 前者給 B 的必要條件；後者給 B 的充分條件，不互換。 |
| 並非全部/全部不是 | 否定的範圍不同；重組時保留量詞與不確定性。 |

「可能無法處理全部請求」可包含全部失敗或只有部分失敗的可能性，不等於確定只能處理部分請求，也不保證至少一個請求成功。避免用更流暢的句子加入這些結論。

「若 A，執行 B」不排除其他條件也能執行 B；「A 之後重新檢查 B」包含檢查動作與順序，不只是要求 B 為真。

## 量值與證據

- 同時保留比較基準、時間範圍、樣本單位、版本與有效位數。「約」不刪成確定值；端點不明時不自行改成包含或排除端點。
- 百分比與百分點分開。例如比率由 40% 升至 50%，差值為 10 個百分點，相對增幅為 25%。若原文混淆，依主檔的任務界線決定是另列問題還是明示更正。
- 保留 MB/MiB、GB/GiB、位元/位元組等原有制式，未指定時不猜測或靜默換算。
- 「未達顯著」不能直接寫成兩組相同；「未找到支持證據」不能直接寫成已證明錯誤。這些是證據主張的區別，不取代實際統計或研究審查。
- 分開「預計執行、已撰寫、已實作、已執行測試、已於指定條件驗證」。只描述來源已支持的完成狀態。

數字與情境均為自訂示例；不得將示例值當作其他任務的結果。

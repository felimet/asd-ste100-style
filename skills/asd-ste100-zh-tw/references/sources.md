# 來源與規則對照

## ASD-STE100

- [ASD-STE100 Issue 9 官方 PDF](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)，版本日期為 2025-01-15。

以下為英文標準原則與繁體中文改編的對照。PDF 頁碼自第一頁起算。

| 原文定位 | 原則摘述 | 中文改編 |
| --- | --- | --- |
| Rule 1.11，PDF 第 45 頁 | 同一項目名稱一致。 | 依專案詞彙表統一名稱，保留不同概念的區別。 |
| Rule 3.6，PDF 第 67 頁 | 主動語態；敘述文字允許未知施事者的例外。 | 已知主體寫清楚；未知原因或主體不補造。 |
| Rules 4.1–4.4，PDF 第 77 頁 | 清楚短句、完整資訊、清單與邏輯銜接。 | 按中文語意拆句，保留必要連接詞。 |
| Rules 5.1–5.5，PDF 第 87 頁 | 程序句最多 20 個英語單字；單句指令保留同步例外，前提先行，備註只提供資訊。 | 不換算中文字數；保留同步關係、前提與指令用途。 |
| Rules 6.1–6.6，PDF 第 95 頁 | 漸進說明、一段一主題；敘述句最多 25 個英語單字、段落最多六句。 | 採用資訊分層；不把英語字數或段落句數當中文合規門檻。 |
| Rules 7.1–7.3，PDF 第 103 頁 | 安全指示表達風險等級、條件或命令與後果。 | 保留原有警告與等級，不增造設備危害或程序。 |
| Section 8，PDF 第 107 頁起 | 英文標點與英語計字規則。 | 依中文及文件格式慣例處理標點；命令及介面字串維持原樣。 |

英文詞典、詞性、動詞時態與多詞名詞限制不直接移植為中文限制。中文規則是自訂改編，不是官方中文標準或認證依據。

# 來源與規則對照

ASD-STE100 Simplified Technical English 是 ASD 的註冊商標。本專案為獨立的第三方指引，與 ASD、STEMG 無隸屬、合作、認證或背書關係，也不提供 STE 合規。

## ASD-STE100

- [ASD-STE100 Issue 9 官方 PDF](https://www.asd-ste100.org/assets/files/ASD-STE100_ISSUE9.pdf)，版本日期 2025-01-15。本 skill 依據 Issue 9；下表的規則編號、PDF 頁碼與字數上限均與該 PDF 相符。
- [ASD 官方 FAQ](https://www.asd-ste100.org/STE_faq.html)：STE 為維修文件而發展，不針對一般用途寫作；FAQ 也說短句、一句一主題、主動語態等許多原則可用於其他寫作情境。本 skill 據此只取部分原則，效果另見下方證據界線。

以下為英文標準原則與繁體中文改編的對照。PDF 頁碼自第一頁起算。

| 原文定位 | 原則摘述 | 中文改編 |
| --- | --- | --- |

| Rule 1.11，PDF 第 45 頁 | 同一項目名稱一致。 | 依專案詞彙表統一名稱，保留不同概念的區別。 |

| Rule 3.6，PDF 第 67 頁 | 主動語態；敘述文字允許未知施事者的例外。 | 已知主體寫清楚；未知原因或主體不補造。 |

| Rules 6.1–6.6，PDF 第 95 頁起 | 漸進說明、一段一主題；敘述句最多 25 個英語單字、段落最多六句。 | 採用資訊分層與一段一主題；不把英語字數或段落句數當中文合規門檻。 |

英文詞典、詞性、動詞時態與多詞名詞的字數限制不直接移植為中文限制。中文規則是自訂改編，不是官方中文標準或認證依據。

## 本專案的設計選擇與證據界線

- 程序用編號步驟標出順序、敘述文字以段落組織相關資訊（Rule 6.4，PDF 第 99 頁）且一段一主題（Rule 6.5）、複雜內容用垂直清單（Rule 4.3，標示符號依適用的文件規範）出自 STE。三項門檻、編號與項目符號的選擇、表格、補充讀檔條件，以及潤飾時的更正界線，是本專案的編輯規則；SKILL.md 規則 6 標題的「STE 條列風格」只指上述出自 STE 的部分。
- 主檔保留必要的語意檢查，補充文件提供細節。列出觸發條件是為了減少漏讀；格式驗證與少量案例不能證明模型每次都會觸發，也不能證明一定節省延遲或 token。
- 臺灣用語預設不是完整受控詞典；清楚表達是設計目標，未有讀者研究支持「等同 STE」「消除歧義」或「保證自然中文」等效果主張。
- 圖解、HTML 與影片為使用者需要時的解說延伸，不是 STE 合規項目。
- 評測紀錄在 [GitHub repo 的 tests/](https://github.com/felimet/asd-ste100-style/tree/main/tests)，不隨 skill 安裝。這些評測題目數少、多為單次取樣，部分題目是針對新規則自擬，限制寫在各紀錄中。

## HTML 無障礙的獨立來源

- [WCAG 2.2](https://www.w3.org/TR/WCAG22/)：語言標記（3.1.1）、鍵盤操作（2.1.1）、文字對比（1.4.3）與焦點可見（2.4.7）。只遵守本 skill 的簡要提示，不代表通過完整 WCAG 驗收。
- [H57：以 html 的 language 屬性標示主要語言](https://www.w3.org/WAI/WCAG22/Techniques/html/H57)。繁體中文頁面使用 `zh-Hant` 是本專案的具體選擇，不是 STE 規定或所有頁面唯一可用的標記。
- [C39：使用 prefers-reduced-motion](https://www.w3.org/WAI/WCAG22/Techniques/css/C39)：處理非必要互動動畫的一種技術，不是唯一強制實作方式。

影片交付狀態與工具授權規則屬本專案的交付慣例，不歸因於 STE。

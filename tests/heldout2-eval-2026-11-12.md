# 第二組保留題（base、lean、v120；agy、Codex、Claude Code）

日期：2026-11-12。原始回覆與評審紀錄見 [heldout2-eval-2026-11-12.json](heldout2-eval-2026-11-12.json)；題目見 [eval/heldout2-prompts.json](eval/heldout2-prompts.json)；判定規則在看結果前寫定於 [eval/heldout2-protocol.md](eval/heldout2-protocol.md)（commit 36e296d，修訂 1047a56、b4a661c）。

## 結論

- 事前登錄的規則 1 在 agy 端成立：v120 − lean 的 atoms 配對差 −0.0434，bootstrap 95% CI −0.090 至 −0.0035。依規則，1.3.0 不採用 v120 的 SKILL.md，改回 1.1.1 的 SKILL.md 文字（git blob `08ece2d4`）；references、README 與封裝的修正保留。
- 這個結果寫成「符合事前登錄的退步條件」，不是「證明 v120 較差」。24 題中只有 7 題有差異（6 負 1 正），精確 sign-flip 檢定雙尾 p = 0.094；拿掉 6 個負差題中的任何一題，規則 1 就不成立；單看任一位評審也不成立。
- v120 在另外兩個生成者與 lean 的 atoms 差距都很小，CI 都包含 0：Codex +0.0024（−0.017 至 0.020），Claude −0.0080（−0.040 至 0.027）。

## 設計

- 24 題（g01 至 g24），9 種題型。撰寫者看不到 skill；修改 skill 的人在評測結束前沒有讀題目內容。
- 3 臂：`base`（不載入 skill）、`lean`（1.1.1）、`v120`（1.2.0 候選）。各臂檔案的 sha256 在結果檔的 `arms`。lean 的 SKILL.md 雜湊 `53d02152…` 是 git blob `08ece2d4` 的 CRLF 版本，內容相同。
- 生成者：
  - agy，`gemini-3.8-flash-high`。原定 Gemini 4 Argon，開跑後額度用完而改用（見 protocol 修訂）。
  - Codex CLI 0.166.0，`gpt-6.1-sol`，reasoning effort medium。
  - Claude Code 2.1.319，`--model sonnet`，effort medium，不載入 CLAUDE.md、使用者設定、plugins、hooks、MCP 與 auto memory。
- 每臂每題取樣 1 次，共 216 筆生成。每題由另外兩家各評一次，每次同時評同一生成者的三臂回覆，共 144 份評審（每則回覆得到兩份評分）；標籤順序依題號與評審輪替。
- 所有生成都以 `/asd-ste100-zh-tw` 或 `$asd-ste100-zh-tw` 明確呼叫 skill，沒有測自動觸發。

## 判定（依 protocol）

- 規則 1：agy −0.0434 ≤ −0.03，CI 上界 −0.0035 < 0，成立。Codex +0.0024 與 Claude −0.0080 不成立。
- 規則 2：三個生成者的平均 −0.0163，高於 −0.02，不成立。
- 規則 3：v120 的機械檢查全過率在三個生成者都不低於 lean，不成立。
- 結果：規則 1 成立，不採用 v120 的 SKILL.md。
- Claude 端 v120 − base 的 CI 上界 0.050 不小於 0，因此 README 不需要加註「可能減少必要內容」。
- 穩健性（排除 progress、emotional、short_qa，n = 17）：agy −0.051（−0.112 至 −0.007），Codex +0.003（−0.024 至 0.028），Claude +0.010（−0.022 至 0.051）。Claude 的方向與全部題目相反（全部題目 −0.008）。

## 規則 1 的敏感度（事後檢查，不改變判定）

- bootstrap 本身穩定：種子 0 至 499 的上界全部 < 0；重抽 100,000 次的上界是 −0.0035。另一份獨立重算的 BCa 區間是 −0.100 至 −0.009。
- 差異集中在少數題：17 題差 0，6 題負，1 題正（g03 +0.167）。精確 sign-flip 檢定雙尾 p = 0.094。獨立重算的 t 檢定 p = 0.069，Wilcoxon 精確檢定 p = 0.109。
- 拿掉 g01、g02、g08、g10、g15、g21 中的任何一題，規則 1 都不成立。
- 單看一位評審，規則 1 都不成立：Codex 評審 −0.029（−0.063 至 0.000），Claude 評審 −0.058（−0.131 至 0.006）。

BCa、t 檢定與 Wilcoxon 來自獨立重算的腳本，沒有納入 repo；其餘數字可用下方的命令重跑。

## agy 退步題的逐題觀察（事後判讀，未驗證）

- g15（除錯，−0.40）：兩位評審都判 v120 缺少驗證步驟。v120 回覆先斷定原因再列出四項原因，沒有驗證段落；lean 有「驗證步驟」。v120 把錯誤說明列的「可能原因」改成「原因」，並只在原因未確定時才寫確認方法；這段文字可能與缺漏有關。但每格只取樣 1 次，且 Claude 與 Codex 在同一份 v120 文字下沒有這個缺漏，所以這只是單題、單次取樣的假設，沒有驗證。
- g01（短答，−0.17）：v120 回覆沒有寫 PUT 的冪等性，只有 Claude 評審扣分。v120 的篇幅規則寫「放不下的補充就刪除」，可能讓短答刪掉第三個重點；但該題的 50 字上限沒有用滿（32 字）。
- g02、g08、g21：都只有一位評審扣分。g10：兩位評審都扣分（各 −0.25），且兩臂的回覆都把整段答案重複一次。差異可能來自回覆的改寫方式、評審的解讀或單次取樣的變異；例如 g21 的 v120 回覆列出原文沒有的待確認事項，Codex 評審判為新增資訊。
- 沒有看到長度與 atoms 差的明確關聯：v120 平均短約 25%，但 24 題中 17 題的 atoms 差為 0，資料不足以排除長度的影響。

## v120 的收益與代價

- 收益：g02 的字數上限在 agy 與 Claude 都改為通過（各 1 題）；agy 字數再少 25%，整段重複由 3 則降到 2 則；Claude 的 tone 平均由 4.67 升到 4.77；Claude 的捏造旗標只有 Codex 評審有變化（8/24 降到 5/24，agy 評審兩臂都是 0/24）。這些差異都很小，本檔沒有為其中任何一項計算 CI。
- 代價：agy 的 atoms −0.043；Codex 的 directness −0.13（−0.25 至 −0.02），評審首選率（評審選為最佳回覆的比例）由 0.375 降到 0.167。

## 限制

- n = 24，每格 1 次取樣；多數題的 atoms 接近上限，差異集中在少數題。
- agy 改用 Gemini 3.8 Flash，結果不能和 2026-11-09、11-10 用 Argon 的紀錄直接比較。
- agy 與 Codex 會載入作者的全域指令，對三臂相同，但會影響回覆結構；例如 agy 在 g10、g15 的段落標題沿用該指令的除錯順序。Claude 端完全隔離。
- 評審與生成者是同三個模型家族。評審輸出 atoms 與捏造旗標的布林值、directness、readability、tone 的 1 至 5 分，以及最佳回覆標籤，沒有寫理由。
- 標籤順序只平衡絕對位置：每個臂在每個位置各出現 8 次，但每位評審在每個生成者的 24 題中，lean 排在 v120 前面 16 題、後面 8 題，所以前後順序效應沒有平衡。
- 報告的「讀 SKILL」欄在 agy 全為 0，低估了 skill 的使用。agy 不顯示 SKILL.md 讀取，但有以絕對路徑讀取 references；推論 skill 內容由呼叫前綴直接注入。
- 沒有測自動觸發，也沒有測常駐規則模式。
- harness 的 bootstrap 取 `ms[int(0.025 n)]` 與 `ms[int(0.975 n)]`，兩端的索引差一，名目涵蓋率是 95.025%。歷次紀錄都用同一演算法，這次沒有修改。
